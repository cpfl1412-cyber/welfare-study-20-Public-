# 20일 완성 장애인복지 — 이론·퀴즈 PWA

면접(2026-12-10)과 사회서비스팀 실무를 준비하기 위한 **20일 × 5문항** 학습 앱입니다.
서버·계정·외부 API가 없고, 모든 기록은 기기 안(`localStorage`)에만 저장됩니다.

## 쓰는 법

- 휴대폰에서 폴더의 `index.html`을 열거나, 아래처럼 로컬 서버를 띄워 접속합니다.
  ```bash
  cd work/welfare-study-20
  python3 -m http.server 8765
  # 브라우저에서 http://localhost:8765
  ```
- 사파리 공유 → **홈 화면에 추가**를 하면 앱처럼 열리고 오프라인에서도 동작합니다.
- 이론 화면 아래 재생 버튼으로 **음성 듣기**(0.9x·1.0x·1.2x·1.4x, 반복, 다음 Day 이어듣기)를 쓸 수 있습니다.

## 무엇이 들어 있나

| 화면 | 내용 |
| --- | --- |
| 홈 | 진도율·완료 일수·평균 점수·오답 수, 20일 카드, 이어서 공부·이어듣기 |
| Day 이론 | 5개 섹션(개념·기준·실무 예시·주의점·면접 포인트), 표·실무 팁, 문단별 듣기 |
| 퀴즈 | Day당 5문항(OX·4지선다), 즉시 정답/오답 표시 + 해설, 점수 저장 |
| 오답노트 | 틀린 문제만 모아 다시 풀기, 맞히면 목록에서 제거 |

- Day 1~10: 장애등급제·15개 유형·등록/심사·활동지원·발달장애인법·장차법·복지관 조직·발달재활·인권/학대·재무회계
- Day 11~20: 연금/수당·고용·거주시설·UD/BF·보조기기/이동·평생교육/건강·의사결정지원·가족지원·통합돌봄·총정리/면접

## 파일 구조

```
index.html            화면 껍데기, CSP·PWA 메타
style.css             모바일 우선 스타일(라이트/다크)
app.js                라우터·홈·이론·퀴즈·오답노트·TTS 상태 머신
data.js               생성물: 20일 이론 + 100문항 (build/에서 생성)
manifest.webmanifest  PWA 설정
sw.js                 오프라인 캐시
icons/                아이콘(svg·png·maskable)
preview-*.png         검증용 화면 미리보기
build/
  days/day01~20.json  학습 데이터 원본
  build_data.py       JSON → data.js (구조·정답·금지어 검증 포함)
  validate.py         data.js 아티팩트 역검증
  gen_icons.py        아이콘 생성
  verify_app.py       로컬 서버 + 헤드리스 브라우저 검증/스크린샷
  verify_tts.py       음성 듣기 상태 머신 검증(모의 speechSynthesis)
```

## 데이터 고치기

```bash
python3 build/build_data.py   # build/days/*.json -> data.js
python3 build/validate.py     # 구조·정답 인덱스·개인정보 금지어 검사
```

`style.css`·`app.js`를 고치면 `index.html`의 `?v=` 값과 `sw.js`의 `CACHE` 버전을 함께 올려 주세요.
그래야 홈 화면 앱이 이전 캐시를 붙잡지 않습니다.

## 원칙

- 외부 통신 없음: CSP `connect-src 'self'`, 모든 자산은 같은 폴더. 실행 중 외부 요청 0건(검증 스크립트로 확인).
- 개인정보 없음: 실명·가족·직장·연락처를 코드와 데이터에 넣지 않았고, `validate.py`가 금지어를 검사합니다.
- 기록은 기기 안에만: 로그인 없음, 서버 전송 없음, 초기화 버튼으로 삭제.
